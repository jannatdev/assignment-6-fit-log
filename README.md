## ✅ Project name:

 A6-Fit Log Website


## 🎯 Description:

A6-Fit Log is an interactive workout website that helps users explore exercises and manage their fitness plans online. Users can browse different workouts, save exercises, add them to their personal plan and track workout details such as duration, calories, sets and reps. The website provides a simple and responsive interface for an easy fitness experience on different devices.


## 🚀 Used Technologies:

1. Next.js
2. Tailwind CSS
3. JavaScript(ES6)
4. daisiui
5. react.toastify    



## 🎮 5 key features of the project:

1. Workout Library - Browse and explore a variety of exercises with details such as muscle groups, equipment, difficulty and instructions.
2. Personal Workout Plan - Add exercises to a personal plan and manage planned workouts easily.
3. Save Exercises - Save favorite exercises for quick access later.
4. Workout Tracking - Track workout duration, calories burned, sets and reps.
5. Responsive & Interactive UI - A clean, responsive interface that works smoothly across desktop, tablet and mobile devices.
